EXPERIMENT 04 Symmetric Encryption

Advanced Encryption Standard (AES): Rijndael Transformations & AES-GCM

Master the global standard for symmetric encryption (FIPS PUB 197). Explore internal 4x4 state matrix transformations (SubBytes, ShiftRows, MixColumns, AddRoundKey) and execute modern AES-GCM authenticated encryption.

Current Global Standard: AES is the dominant symmetric encryption algorithm worldwide, securing TLS/HTTPS connections, wireless networks (WPA3), mobile storage, and governmental classified data.

Aim of the Experiment

To investigate the internal algebraic architecture and practical cryptographic deployment of the Advanced Encryption Standard (AES), examining the four round operations on a 4x4 byte state matrix and executing authenticated encryption using AES-GCM with dynamic nonces and tags.

Key Learning Outcomes

  • Understand the 128-bit block size and key size variations (AES-128: 10 rounds, AES-192: 12 rounds, AES-256: 14 rounds).
  • Analyze the four transformations: SubBytes (S-box), ShiftRows (row permutation), MixColumns (multiplication in GF(2^8)), and AddRoundKey.
  • Implement practical Authenticated Encryption with Associated Data (AEAD) using native Web Crypto AES-GCM.
  • Observe how modifying a single byte in ciphertext or authentication tag triggers immediate cryptographic verification failure.

Theoretical Principles of AES

1. Background & Specifications

Selected by NIST in 2001 after an open international competition, AES is based on the Rijndael cipher developed by Belgian cryptographers Vincent Rijmen and Joan Daemen. AES standardizes a fixed block size of 128 bits (16 bytes).

Cipher Variant Key Length (bits) Key Length (words) Number of Rounds (Nr) Expanded Key Size (words)
AES-128 128 bits (16 bytes) 4 words 10 rounds 44 words
AES-192 192 bits (24 bytes) 6 words 12 rounds 52 words
AES-256 256 bits (32 bytes) 8 words 14 rounds 60 words

2. The 4x4 State Matrix & Four Round Operations

The 16 bytes of data are arranged into a 4x4 two-dimensional column-major state matrix: 

[ S_0,0   S_0,1   S_0,2   S_0,3 ]
[ S_1,0   S_1,1   S_1,2   S_1,3 ]
[ S_2,0   S_2,1   S_2,2   S_2,3 ]
[ S_3,0   S_3,1   S_3,2   S_3,3 ]
1. SubBytes (Non-linear Byte Substitution):

Each byte in the state is independently replaced by its multiplicative inverse in the finite field GF(2^8) modulo m(x) = x^8 + x^4 + x^3 + x + 1, followed by an affine transformation. This provides strong resistance against differential and linear cryptanalysis.

2. ShiftRows (Cyclical Row Permutation):

Row 0 is not shifted. Row 1 is cyclically shifted left by 1 byte. Row 2 is cyclically shifted left by 2 bytes. Row 3 is cyclically shifted left by 3 bytes. This achieves inter-column diffusion.

3. MixColumns (Galois Field Matrix Multiplication):

Each column of four bytes is treated as a 4-term polynomial over GF(2^8) and multiplied modulo x^4 + 1 with a fixed polynomial c(x) = {03}x^3 + {01}x^2 + {01}x + {02}. (Omitted in the final round Nr).

4. AddRoundKey (XOR with Subkey):

The 128 bits of the state matrix are XORed with the corresponding 128-bit round subkey derived from the Key Expansion schedule.

3. AES-GCM (Galois/Counter Mode) Authenticated Encryption

In modern production networks, AES is rarely used as a raw block cipher. Instead, it is paired with Galois/Counter Mode (GCM), an AEAD scheme defined in NIST SP 800-38D.

  • CTR Mode Confidentiality: Generates a keystream by encrypting sequential counter values initialized with a fresh 96-bit (12-byte) random nonce.
  • GMAC Authentication Tag: Computes a 128-bit universal hash tag using polynomial arithmetic over the Galois field GF(2^{128}).
  • Nonce Uniqueness Rule: An initialization vector (nonce) must never be reused with the same key. Reusing a nonce catastrophic allows an adversary to forge authentication tags and recover plaintext XOR differences.

Simulation Procedure

  1. Navigate to the Practice tab.
  2. Modern AES-GCM Tool:
    • Select key size: AES-128 or AES-256.
    • Click Generate New Random Key (or enter a known hex key).
    • Enter your plaintext payload (e.g. Top Secret University Research Payload).
    • Click Encrypt (AES-GCM). The Web Crypto API generates a fresh 96-bit nonce, encrypts the payload, and produces a 128-bit GMAC tag.
    • Click Decrypt (AES-GCM) to verify authenticated recovery.
    • Tamper Detection Test: Modify one character in the Ciphertext or Tag field and click Decrypt. Observe the authentication failure alert.
  3. Educational State Matrix Visualizer:
    • Inspect the interactive 4x4 state matrix below.
    • Observe the sequential transformation of bytes through SubBytes, ShiftRows, and MixColumns.

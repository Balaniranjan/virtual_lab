EXPERIMENT 01 Classical Cryptography

Classical Cipher Techniques: Caesar, Playfair, and Hill Ciphers

Investigate historical substitution mechanisms: monoalphabetic shifting (Caesar), polygraphic 5x5 keyword matrix transformations (Playfair), and modular linear algebra over Z_26 (Hill cipher).

Educational Legacy Primitive
Cryptographic Notice: Caesar, Playfair, and Hill ciphers are strictly historical teaching demonstrations. They are trivial to break via frequency analysis, known-plaintext linear attacks, and brute force, and must never be used for real-world confidential data.

Aim of the Experiment

To understand, implement, and analyze classical substitution cipher techniques by exploring the mathematical principles, algorithm mechanics, and cryptanalytic vulnerabilities of the Caesar Cipher, Playfair Cipher, and Hill Cipher.

Key Learning Outcomes

  • Perform character-by-character modular shifts modulo 26 using the Caesar cipher.
  • Construct a 5x5 keyword matrix and execute digraph substitution rules under the Playfair cipher with proper padding conventions.
  • Apply modular matrix multiplication, determinant calculation, and matrix inversion modulo 26 to encrypt and decrypt polygraphic blocks in the Hill cipher.
  • Examine how frequency analysis breaks monoalphabetic ciphers and understand the mathematical conditions required for Hill key invertibility.

Theoretical Foundations

1. Caesar Cipher (Shift Substitution)

The Caesar cipher is one of the earliest known monoalphabetic substitution ciphers, historically used by Julius Caesar. Each letter in the plaintext is shifted by a fixed integer key k (where 0 ≤ k ≤ 25) across the 26-letter Latin alphabet.

Mathematical Formulation:

Assign numerical values to letters: A = 0, B = 1, C = 2, ... Z = 25.

Encryption: C = (P + k) mod 26

Decryption: P = (C - k + 26) mod 26

Security Vulnerability: With only 26 possible keys (key space size 26), an attacker can easily execute an exhaustive brute-force search. Furthermore, because each letter maps to exactly one ciphertext letter, standard English letter frequencies (e.g. 'E', 'T', 'A', 'O') are preserved directly in the ciphertext.

2. Playfair Cipher (Digraphic Substitution)

Invented in 1854 by Charles Wheatstone and promoted by Lord Playfair, this was the first practical digraphic substitution cipher. Instead of individual characters, pairs of letters (digraphs) are transformed using a 5x5 key matrix.

Matrix Construction:

  • A 5x5 grid (25 cells) is filled with a keyword (excluding duplicate letters), followed by remaining alphabet letters in alphabetical order.
  • I/J Convention: Since the English alphabet has 26 letters and the grid has 25 cells, 'I' and 'J' share a single cell.

Plaintext Digraph Preparation:

  • The plaintext is divided into pairs of letters.
  • If a pair consists of identical letters (e.g. "EE"), an 'X' (or 'Q') is inserted between them.
  • If the final text has an odd length, a trailing 'X' (or 'Z') is appended.

Transformation Rules:

  1. Same Row: Replace each letter with the letter to its immediate right (wrap around to the first column).
  2. Same Column: Replace each letter with the letter immediately below it (wrap around to the top row).
  3. Rectangle: Replace each letter with the letter in the same row but in the column of the other letter.

Decryption applies inverse rules: shift left for same row, shift up for same column, and rectangle column swap. Note that filler 'X' characters remain in decrypted text.

3. Hill Cipher (Polygraphic Linear Algebra)

Invented by mathematician Lester S. Hill in 1929, the Hill cipher uses linear algebra and modular arithmetic to encrypt blocks of m letters simultaneously.

Mathematical Formulation:

Plaintext characters are partitioned into vectors of length m: P = [p_1, p_2, ..., p_m]^T.

Encryption: C = (K × P) mod 26

Decryption: P = (K^{-1} × C) mod 26

Invertibility Condition modulo 26:

For the key matrix K to be invertible modulo 26, its determinant det(K) must be coprime to 26:
gcd(det(K) mod 26, 26) = 1

Since 26 factors into 2 × 13, the determinant must not be divisible by 2 or 13.

2x2 Matrix Inverse Formula:
K^{-1} = det(K)^{-1} × [ [d, -b], [-c, a] ] mod 26

Simulation Procedure

  1. Navigate to the Practice tab.
  2. Select your desired cipher sub-module using the tabs: Caesar Cipher, Playfair Cipher, or Hill Cipher.
  3. For Caesar Cipher:
    • Enter a plaintext message in the input text area.
    • Adjust the shift slider or type a numeric key value between 0 and 25.
    • Click Encrypt to observe the character transformation table and the shifted alphabet strip.
    • Copy the ciphertext into the input, enter the same shift key, and click Decrypt to verify recovery.
  4. For Playfair Cipher:
    • Enter a keyword (e.g. MONARCHY) and observe how the 5x5 matrix is automatically populated.
    • Input plaintext (e.g. INSTRUMENTS).
    • Click Encrypt to observe digraph splitting, filler insertion, and rule applications (row, column, or rectangle).
    • Inspect highlighted coordinates on the interactive 5x5 matrix.
  5. For Hill Cipher:
    • Select matrix dimension: 2x2 or 3x3.
    • Enter numerical matrix values (e.g. [[9, 4], [5, 7]]).
    • Observe determinant calculation and invertibility validation against 26.
    • Click Encrypt or Decrypt to trace vector multiplication step-by-step.
  6. Proceed to the Posttest tab to assess your conceptual understanding.

Guided Demonstration Examples

Review these canonical textbook examples to observe step-by-step transformations before practicing with custom parameters.

Example 1: Caesar Cipher (k = 3 - Augustus Shift)

Plaintext: MEET ME AFTER THE TOGA PARTY

Shift Key: k = 3

Transformation: Each letter shifted by +3 mod 26: M(12)->P(15), E(4)->H(7), T(19)->W(22)...

Ciphertext: PHHW PH DIWHU WKH WRJD SDUWB

Example 2: Playfair Cipher (Keyword: "MONARCHY")

Keyword: MONARCHY | Plaintext: BALLOON

Digraph Preparation: 'LL' split with 'X', padded trailing letter -> BA LX LO ON

Matrix 5x5:

M  O  N  A  R
C  H  Y  B  D
E  F  G  I  K
L  P  Q  S  T
U  V  W  X  Z
  • BA (Row 1 Col 3, Row 0 Col 3) -> Same Column -> IB
  • LX (Row 3 Col 0, Row 4 Col 3) -> Rectangle Swap -> SU
  • LO (Row 3 Col 0, Row 0 Col 1) -> Rectangle Swap -> PM
  • ON (Row 0 Col 1, Row 0 Col 2) -> Same Row -> NA

Ciphertext: IB SU PM NA

Example 3: Hill Cipher 2x2 Matrix

Plaintext: HELP -> Digraphs HE (7, 4), LP (11, 15)

Key Matrix: K = [ [3, 3], [2, 5] ]

Determinant: det = (3*5 - 3*2) = 15 - 6 = 9.
gcd(9, 26) = 1. Modular inverse of 9 mod 26 = 3 (since 9 × 3 = 27 ≡ 1 mod 26).

Vector 1 (H, E): [3*7 + 3*4, 2*7 + 5*4] = [33, 34] ≡ [7, 8] mod 26 -> (H, I)

Ciphertext: HIAT
